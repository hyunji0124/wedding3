휴대폰 청첩장 키트

설정 파일 하나만 고치면 청첩장이 완성됩니다. 개발 지식이 없어도 괜찮아요.

미리보기

아래 화면을 직접 눌러 볼 수 있어요.

휴대폰 청첩장 신랑(또는 신부)의 휴대폰을 몰래 열어보는 설정. 암호는 결혼식 날짜예요. 새 창에서 열기
미리보기가 비어 있거나 사진이 안 보이면, 이 폴더 안의 파일을 옮기거나 이름을 바꾸지 않았는지 확인해 주세요. 폴더 구조는 그대로 두어야 합니다.

설정 점검

현재 config.js에 들어 있는 값을 읽어서 아직 안 바꾼 항목을 알려드려요. 파일을 고치고 이 페이지를 새로고침하면 다시 점검됩니다.

1내용 바꾸기 — config.js

이름, 날짜, 장소, 계좌, 인사말 등 모든 내용은 config.js 파일 하나에 들어 있어요.

  1. config.js 파일을 메모장으로 엽니다 Windows: 파일을 오른쪽 클릭 → "연결 프로그램" → 메모장.
    Mac: 파일을 오른쪽 클릭 → "다음으로 열기" → 텍스트 편집기. (열린 뒤 메뉴 "포맷 → 일반 텍스트 만들기"를 한 번 눌러 주세요)
    더 편하게 하려면 무료 프로그램 VS Code를 추천해요.
  2. 따옴표 안의 글자만 바꿉니다 
    name: "김도윤",     ←  "김도윤" 부분만  "홍길동" 처럼 바꾸세요
day: 19,            ←  숫자는 따옴표 없이 그대로 숫자만 바꾸세요
    따옴표(")와 쉼표(,)는 지우면 안 됩니다. 줄바꿈이 필요하면 \n을 넣으세요.
  3. 필요 없는 항목은 비워 둡니다 예: 계좌번호를 안 넣으려면 account: "" 로 두세요. 그러면 "마음 전하기" 화면이 자동으로 숨겨져요.
  4. 저장합니다 (Ctrl+S / ⌘+S) 파일 이름과 위치는 바꾸지 마세요. 저장 형식은 UTF-8이어야 합니다. (메모장·텍스트 편집기 기본값)
  5. 이 페이지를 새로고침해서 "설정 점검"과 미리보기를 확인합니다

2사진 바꾸기 — photos 폴더

photos 폴더 안의 샘플 그림을 내 사진으로 바꿔 넣으면 됩니다.

파일쓰이는 곳권장
main.jpgRPG 기념사진, 휴대폰 배경화면세로 사진, 가로 1000px 정도
1.jpg ~ 4.jpg휴대폰 앨범 4장세로 사진, 가로 800px 정도
share.jpg카카오톡으로 보낼 때 미리보기 이미지가로 1200 × 세로 630px
  1. 사진을 준비합니다 휴대폰 원본은 너무 커서(5~10MB) 느려요. 카카오톡으로 나에게 보내기 → 다시 저장하면 알맞게 줄어듭니다. 또는 squoosh.app에서 줄일 수 있어요.
  2. 파일 이름을 똑같이 맞춥니다 main.jpg, 1.jpg … 처럼 샘플과 같은 이름으로 바꾼 뒤 덮어쓰기 하세요. 다른 이름을 쓰고 싶으면 config.js의 photos 항목도 같이 바꿔 주세요.
  3. 확장자를 확인합니다 .jpg 또는 .png만 사용하세요. 아이폰의 .heic는 열리지 않으니 사진 앱에서 "JPEG로 저장"하거나 카카오톡을 거쳐 주세요.
얼굴이 들어간 사진을 인터넷에 올리는 것이니, 두 분이 공개해도 괜찮은 사진인지 한 번 더 확인해 주세요.

3인터넷에 올리기

내 컴퓨터에서만 보이는 파일을 누구나 열 수 있는 주소(링크)로 만드는 단계예요. 두 가지 방법 중 하나를 고르세요.

방법 A — GitHub Pages (추천: 무료, 주소가 깔끔, 수정도 쉬움)

  1. GitHub 가입 github.com/signup에서 계정을 만듭니다. 아이디는 주소에 들어가니 간단한 영문으로 정하세요. (예: dyun-syeon)
  2. 저장소(폴더) 만들기 오른쪽 위 + → New repository. Repository name에 wedding 입력, Public 선택, Create repository.
  3. 파일 올리기 만들어진 화면에서 uploading an existing file 링크를 누릅니다. 이 키트 폴더 안의 내용물 전부(index.html, config.js, common.js, phone, photos 폴더)를 끌어다 놓고, 아래 Commit changes를 누릅니다.
    폴더째 끌어다 놓으면 폴더 구조가 그대로 올라갑니다. 압축 파일(zip)을 올리면 안 돼요. 압축을 푼 다음 안의 내용물을 올리세요.
  4. Pages 켜기 저장소 상단 Settings → 왼쪽 메뉴 Pages → "Branch"를 None → main으로 바꾸고 Save.
  5. 주소 확인 1~3분 뒤 같은 화면 위쪽에 주소가 나타납니다. 
    https://아이디.github.io/wedding/           ← 이 안내 페이지
https://아이디.github.io/wedding/phone/     ← 청첩장 (하객에게 보낼 주소)
    하객에게는 phone/로 끝나는 주소를 보내세요.
  6. 나중에 수정하려면 저장소에서 파일을 클릭 → 연필(✏️) 아이콘 → 고친 뒤 Commit changes. 1~2분 뒤 반영됩니다. 사진은 Add file → Upload files로 같은 이름으로 다시 올리면 덮어써져요.

방법 B — Netlify Drop (가장 빠름: 끌어다 놓으면 끝)

  1. app.netlify.com/drop에 접속해 가입(이메일 또는 GitHub)합니다.
  2. 이 키트 폴더 전체를 화면에 끌어다 놓습니다.
  3. 몇 초 뒤 https://무작위이름.netlify.app 주소가 생깁니다. Site settings → Change site name에서 원하는 이름으로 바꿀 수 있어요. (예: dyun-syeon.netlify.app)
  4. 수정할 때는 폴더를 다시 끌어다 놓으면 됩니다.

올리기 전에 내 컴퓨터에서 확인하기

이 폴더의 index.html(지금 보고 있는 파일)을 더블클릭하면 그대로 열립니다. 휴대폰에서 보고 싶으면 인터넷에 올린 뒤 주소를 열어 보세요. 올린 뒤에는 꼭 휴대폰에서 직접 한 번 열어보고, 지도 링크·전화 버튼·계좌 복사가 되는지 확인하세요.

카카오톡 미리보기 설정 (선택)

링크를 카카오톡으로 보내면 제목·설명·사진이 함께 보이는데, 이 내용은 각 청첩장 파일 맨 위에 적혀 있어요. 주소가 정해진 뒤에 바꿔 주세요.

  1. phone/index.html을 메모장으로 엽니다.
  2. 맨 위의 세 줄을 찾습니다. 
    <meta property="og:title" content="도윤 ♥ 서연 결혼합니다">
<meta property="og:description" content="신랑의 휴대폰을 몰래 열어보세요">
<meta property="og:image" content="https://아이디.github.io/저장소이름/photos/share.jpg">
  3. content="…" 안의 글자를 바꿉니다. og:image는 반드시 https://로 시작하는 전체 주소여야 해요. (예: https://dyun-syeon.github.io/wedding/photos/share.jpg)
  4. 저장하고 다시 올립니다.
카카오톡은 한 번 본 링크의 미리보기를 한동안 기억해요. 바꿨는데 예전 모습이 보이면 카카오 공유 디버거에 주소를 넣고 "초기화"를 누르세요.

폴더 구성

📁 wedding/ ├── index.html ← 이 안내 페이지 (하객에게는 안 보내도 됨) ├── README.md ← 자세한 가이드 문서 (같은 내용, 글로 정리) ├── config.js ★ 내용 설정 — 여기만 고치면 됨 ├── common.js ← 공통 기능 (수정 불필요) ├── 📁 phone/ │ └── index.html ← 휴대폰 청첩장 └── 📁 photos/ ★ 사진 — 같은 이름으로 바꿔 넣기 ├── main.jpg, 1.jpg, 2.jpg, 3.jpg, 4.jpg, share.jpg

자주 묻는 질문 · 문제 해결

화면이 하얗게만 나와요

config.js에서 따옴표나 쉼표가 하나 빠진 경우가 대부분이에요. 마지막으로 고친 줄을 다시 보고, 따옴표가 짝이 맞는지, 줄 끝에 쉼표가 있는지 확인하세요. 원본 config.js를 다시 복사해 넣고 하나씩 고쳐도 됩니다.

한글이 깨져서 나와요

파일이 UTF-8이 아닌 형식으로 저장된 거예요. 메모장에서 "다른 이름으로 저장" → 아래 "인코딩"을 UTF-8로 선택해 다시 저장하세요.

사진이 안 보여요

파일 이름과 확장자를 확인하세요. main.JPG(대문자)와 main.jpg는 인터넷에서 다른 파일로 취급돼요. .heic는 지원되지 않습니다. photos 폴더 안에 있는지도 확인하세요.

휴대폰 청첩장 암호를 몰라요

예식 월일 4자리예요. 12월 19일이면 1219. 설정의 date를 바꾸면 암호도 자동으로 바뀝니다. "모르겠어요"를 누르면 암호 없이도 들어갈 수 있어요.

신부의 휴대폰으로 바꾸고 싶어요

config.js에서 phoneOwner: "groom"을 "bride"로 바꾸세요. 말풍선 방향과 상대 이름이 바뀝니다. chat의 from도 그에 맞게 조정하세요.

카카오톡으로 보냈는데 미리보기 사진이 까맣게 나와요

각 청첩장 파일 맨 위 og:image가 아직 https://아이디.github.io/저장소이름/… 그대로라서 그래요. 실제 주소로 바꿔 다시 올린 뒤, 카카오 공유 디버거에서 주소를 넣고 "초기화"를 눌러 주세요. 카카오톡은 한 번 본 미리보기를 기억하기 때문에 초기화를 안 하면 계속 까맣게 보여요.

참석 여부 응답을 모으고 싶어요

구글 폼(forms.google.com)으로 "이름 / 참석 여부 / 동행 인원" 설문을 만들고, 그 링크를 rsvp.url에 넣으세요. "참석할게요"를 누르면 설문이 열립니다.

수정해서 올렸는데 휴대폰(특히 카톡)에서는 예전 화면이 보여요

카카오톡 안의 브라우저는 한 번 본 페이지를 오래 기억해요. 링크 뒤에 ?v=2처럼 아무 글자나 붙여서 열면 새 파일을 받아와요. (예: …/phone/?v=2) 하객에게 보내기 전에 수정을 끝냈다면 신경 쓰지 않아도 되고, 보낸 뒤에 고쳤다면 ?v=2를 붙인 링크를 다시 보내 주세요.

GitHub에 올렸는데 404가 나와요

Pages를 켠 직후에는 1~3분 걸려요. 그래도 안 되면 저장소 최상위에 index.html이 있는지 확인하세요. 폴더 하나를 더 감싸서(예: wedding/wedding/index.html) 올린 경우가 많아요.

주소를 더 예쁘게 하고 싶어요

GitHub 아이디 자체를 주소로 쓰려면 저장소 이름을 아이디.github.io로 만들면 https://아이디.github.io/가 됩니다. 도메인을 따로 사서 연결할 수도 있지만 필수는 아니에요.

이 키트를 다른 사람에게 줘도 되나요

네. 자유롭게 쓰고 나눠 주세요. 도트 글꼴 "갈무리"는 SIL Open Font License로 배포되는 무료 글꼴이고, 샘플 그림은 가상의 인물 일러스트입니다.
